# 🤖 Simple Rule-Based Chatbot

This project is part of the Python Developer Internship Task 8.
The chatbot runs in the terminal and responds to user input using if-elif-else conditions.

# 🔧 Features

Responds to greetings

Handles basic questions

Uses loop for continuous conversation

Stops when user types exit

# 🚀 How to Run

Install Python

Open terminal in project folder

Run:

python chatbot.py

# 📚 Concepts Used

Loops

Conditionals

Input handling

String methods (lower())

# 🧪 Example Conversation
You: hi
🤖 Chatbot: Hi there! How can I help you?

You: what is your name?
🤖 Chatbot: I'm a chatbot created by you!

You: exit
🤖 Chatbot: Goodbye! Have a great day 😊
